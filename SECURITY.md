# Security policy

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub instead: on the repository's
**Security** tab, choose **Report a vulnerability**. You will get an answer within a week, and a fix or a plan
for one as soon as the problem is understood.

## Supported versions

Durastep is not yet at 1.0. Fixes go into the latest release only.

## Running Durastep securely

The [security guide](docs/security.md) covers what Durastep stores, keeping secrets out of workflow data, a
dedicated database user with the exact privileges it needs, TLS, encrypting workflow data at rest with key
rotation, what can and cannot reach the logs, and retention.
